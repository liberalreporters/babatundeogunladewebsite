# BABS Website Repository Files

Static-site scaffold for the Hon. Babatunde Sunday Ogunlade website.

## Structure
- `index.html` — main homepage, included if available when this package was generated.
- `assets/images/profile/` — approved portraits and biography photographs.
- `assets/images/news/` — featured images for news and press releases.
- `assets/images/gallery/` — event photographs.
- `assets/css/site.css` — optional shared styles for additional pages.
- `assets/js/site.js` — small accessibility/date helpers.
- `data/news.json` — news index data.
- `data/timeline.json` — verified career/public-service timeline.
- `data/gallery.json` — gallery metadata.
- `news/`, `gallery/` — article/gallery implementation notes.
- `privacy.html`, `404.html`, `robots.txt`, `sitemap.xml`, `.nojekyll`, `.gitignore`.

## Before publishing
1. Upload these files and folders to the repository root.
2. Back up any existing `index.html` before replacing it.
3. Add approved images and update all filenames, captions and alt text.
4. Replace sample JSON entries with verified material. Sample entries are placeholders, not real news.
5. Check all biography, career, party, contact and campaign details.
6. Update the domain in `robots.txt` and `sitemap.xml` if needed.
7. Connect contact forms to a secure backend or trusted form service before collecting submissions.
8. Review the privacy notice against the site's actual data practices before publication.

Suggested image filenames: `babatunde-ogunlade-portrait.jpg`, `2026-10-12-community-meeting.jpg`, `gallery-event-01.webp`.
